# Kais Ben Hadj Hassen — Portfolio

Personal portfolio of a .NET & Agentic AI engineer. Built with **React 19 + TypeScript + Vite**, **Tailwind CSS v4** and **Framer Motion**.

## Highlights
- Interactive neural-network canvas hero that reacts to the mouse
- Custom cursor, magnetic buttons, 3D tilt + spotlight cards
- Animated multi-agent architecture diagram (El-Las)
- "Ask my AI agent" chat widget (runs locally, no API key needed)
- `Ctrl/⌘ + K` command palette
- Fully responsive, respects `prefers-reduced-motion`

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
Import this repository on [vercel.com/new](https://vercel.com/new) — Vercel detects Vite automatically
(build command `npm run build`, output directory `dist`).

Content lives in `src/data.ts`.
